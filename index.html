Controls

      

        
WASD
Move

        
Space
Jump / fly up

        
Shift
Sprint

        
C
Fly down

        
F / N
Fly mode / no-clip

        
T, Shift+T
Next / previous tool

        
Right mouse
Place piece / add terrain

        
Left mouse
Remove piece / dig

        
Middle mouse
Pick material you're looking at

        
Wheel / [ ]
Size

        
G
Grid size (0.25–2 m)

        
R
Rotate wall / ramp

        
1–0, Q / E
Select material

        
Ctrl+Z
Undo (also undoes collapses)

        
P
Structural physics on / off

        
H
Toggle this help

        
Esc
Release mouse
