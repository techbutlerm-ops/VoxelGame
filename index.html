Controls

      

        
WASD
Move

        
Space
Jump / fly up

        
Shift
Sprint

        
C
Fly down

        
F
Toggle fly mode (fast at altitude)

        
N
Toggle no-clip

        
Left mouse
Dig (hold to keep digging)

        
Right mouse
Build with selected material

        
Wheel / [ ]
Brush size

        
B
Brush shape (sphere / cube)

        
1–0, Q / E
Select material

        
H
Toggle this help

        
Esc
Release mouse
